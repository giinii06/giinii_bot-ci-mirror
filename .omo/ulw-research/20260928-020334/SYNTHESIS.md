## Executive summary

외부 문헌 검증 없이 **자기 코드베이스 실측만으로** 답한다. 결론은 두 갈래다.

**최우선은 새로운 기능이 아니라 구조적 결함 3건이다.** 첫째, `users` 테이블에 9행만 있는데 실제로 대화한 유저는 716명이다 — `/통화량`이 9명만 안다. 둘째, enrich가 DB를 59MB → 119MB로 두 배로 불렸는데 원인은 `message_details.raw` JSON 블롭이다. 셋째, 웹 대시보드가 무인증으로 0.0.0.0에 열려 있다 (README에 이미 기재).

**백필 미수렴은 재현 실패했다.** 내가 가진 "점프 로직이 깨졌다"는 가설은 **시뮬레이션으로 기각되었다.**

| V4 enrich가 DB를 2배로 불렀다 | **CONFIRMED** | 59,255,040 → 119,255,040 바이트. message_details 98,682행이 각 행에 raw JSON 보유 |

## Refuted (내 자신의 가설)

| 가설 | 판정 | 반증 |
|---|---|---|
| "저장 구간 점프가 깨져서 재순회한다" | **기각** | 시뮬레이션에서 475채널 모두 정확히 2회 만에 종료. 루프 논리는 모형상 정상 |
| "채널당 2회 조회 모델이 맞다" | **부분 기각** | 모형은 맞지만 **production이 2,626라운드**를 돌았다. 데이터/환경이 모형과 다르다 — 원인 미확정 |

**남은 백필 미스터리**: production이 왜 2.5× 도는지 확정하지 못했다. 계측 없이 결론 내리지 않겠다. 확인하려면 백필 루프에 채널별 요청 횟수 로그를 넣고 재실행하는 것이 유일한 방법이다.

## Findings by theme

### T1. 데이터 모델 정합성 (최우선, 즉시 확인 필요)
- **F1 [높음]** `users` 9행 vs 작성자 716명. `recordChatCounts`는 유저 행을 만들지 않고, `users` 행은 `ensureUser`(음성 전용)에서만 생성된다. 결과적으로 `/통화량` 카드는 최대 9명만 보여준다.
  - 근거: 실DB 카운트. users=9, distinct author=716.
- **F2 [중간]** `discord_messages`에 `author_id` 인덱스가 없다. 유저별 분석 명령을 추가하려면 반드시 필요.

### T2. 저장 크기와 성장
- **F3 [높음]** `message_details.raw`가 메시지당 JSON 블롭 → enrich 1회로 DB가 2배. 100만 메시지가 되면 대략 1GB급.
  - 대안: raw에서 자주 안 쓰는 필드 제거, 또는 gzip/blake 압축 컬럼 분리.
- **F4 [낮음]** 정리 정책 없음. 메시지 삭제·편집 시 `media_files`가 고아가 될 수 있음 (검증 안 됨).

### T3. 백필 파이프라인
- **F5 [높음]** 미수렴 원인 미확정 (위 Refuted 표 참조). 계측 로그 추가가 선행.
- **F6 [중간]** 429 백오프 코드가 어디에도 없다. enrich 17.8분 실측 구간에서 이미 감속이 관측됐다(8,628 → 6,209건/분).
- **F7 [낮음]** `SKIP_BACKFILL`이 임시 플래그로 .env에 남아 있다. 백필 정상화 후 제거 필요.

### T4. 보안
- **F8 [높음]** 웹 대시보드 무인증 + 0.0.0.0 바인딩 + docker publish. README에 기재된 알려진 문제. `/api/settings` POST가 원격에서 `.env`를 덮어쓸 수 있는지가 이번 조사에서 미확인 — **보안 축 담당이 죽어서 검증 못 함**.

### T5. 누락 기능 (구조적 근거 있는 것만)
- **F9** 166,722건 + 3,389 미디어 + 닉네임 이력이 쌓여 있는데 **사용자에게 돌려주는 명령이 하나도 없다.** AI 분석 9종은 텍스트 컨텍스트만 읽고 `user_profiles`/`message_details`/`media_files`는 전혀 참조하지 않는다.
- **F10** `DISCORD_GUILD_ID`가 1개 길드로 고정 → 나머지 3개 서버 60,694건은 라이브 수신만 되고 과거 미처리.

## Gaps (이 실행이 답하지 못한 것)

- 외부 문헌 검증 전무: Discord 공식 rate limit 수치, discord.js 모듈 문서, SQLite 튜닝 권위 문서. **모든 외부 전제가 미검증 상태.**
- 보안 축 미완료 — 웹 대시보드 실제 익스포저 검증이 안 돌았음.
- AI 분석 축 미완료 — 토큰 비용/컨텍스트 절단 실제 손실 계산이 안 돌았음.
- roulette / 음성 축 미완료.
- **논쟁 라운드 0회** — skeptic이 죽어 어떤 주장도 반증받지 못했다. 위 권고는 전부 미공격 상태다.
