# Giinii Bot 사용법

채팅·음성 통계, 친밀도 그래프, AI 대화/기억, 룰렛을 제공하는 Discord 봇입니다. **`!help`**를 채팅창에 입력하면 명령 요약을 볼 수 있습니다.

## 슬래시 명령어 `/`

| 명령 | 무엇을 하나요? |
| --- | --- |
| `/친밀도 @유저` | 해당 유저와 음성 채널 체류 시간이 겹친 사람 TOP 21 |
| `/친밀도그래프` | 서버 친밀도 관계 2D 이미지 |
| `/통화량` | 전체 음성 채널 체류 시간 순위 |
| `/통계` | 통화·채팅·종합 활동 카드 |
| `/친밀도그래프3d` | Discord 내 3D 그래프 (전용 서버) |
| `/관리자머리끄댕이` | 역할 룰렛 실행 (전용 서버) |

친밀도는 **동일 음성 채널 체류 시간이 겹친 정도**이며, 실제 친분이나 발화량을 뜻하지 않습니다.

## `!` 명령어

### 누구나 (AI 관련 명령은 전용 서버)

| 명령 | 사용 예시 |
| --- | --- |
| `!help` | 전체 도움말 |
| `!model [모델 ID]` | `!model` / `!model deepseek/deepseek-v4.1-flash-1017` |
| `!reasoning [수준]` | `!reasoning` / `!reasoning low` |
| `!memory list` | 내 AI 기억 보기 |
| `!memory delete <번호>` | `!memory delete 3` |
| `!memory clear confirm` | 개인 AI 기억 전체 초기화 |
| `!memory visibility <번호> <private|shareable>` | `!memory visibility 3 shareable` |

### 서버 관리자 (전용 서버)

| 명령 | 사용 예시 |
| --- | --- |
| `!mind status` | AI 판단 상태 조회 |
| `!shared-memory list` | 공용 기억 보기 |
| `!shared-memory add <종류> [@유저] <내용>` | `!shared-memory add fact 이 서버는 저녁에 활발하다` |
| `!shared-memory edit <번호> <내용>` | `!shared-memory edit 3 새 내용` |
| `!shared-memory delete <번호>` | `!shared-memory delete 3` |
| `!shared-memory nickname @유저 <별명>` | 유저 공용 별명 설정 |
| `!타겟 지정 @역할` / `삭제` / `조회` | 룰렛을 사용할 역할 지정 |
| `!관리자_타겟 지정 @역할` / `삭제 @역할` / `조회` | 룰렛 대상 역할 지정 |
| `!들낙감지설치` | 현재 텍스트 채널을 입퇴장 알림 채널로 |
| `!들낙시간지정 30` | 30초 안에 입퇴장하면 기록 |
| `!들낙무시` / `!들낙무시 <채널ID>` / `!들낙무시 해제 <채널ID>` | 제외 채널 조회·추가·해제 |

공용 기억의 종류: `fact`(사실), `preference`(취향), `server_convention`(서버 관습). 유저 지정은 선택입니다.

### 봇 소유자 전용 (`ADMIN_USER_ID`)

| 명령 | 기능 |
| --- | --- |
| `!sync` | 슬래시 명령어 다시 동기화 |
| `!서버목록` | 봇이 참가한 서버 목록 |
| `!서버별명령어 [서버 이름]` | 슬래시 명령 허용 상태 보기 |
| `!서버별명령어 <서버> disable|enable <명령>` | 서버별 슬래시 명령 끄기/켜기 |
| `!도움` | 운영자용 도움말 |

**참고:** 서버 관리자라도 봇 소유자 전용 명령은 쓸 수 없습니다. `!` 명령은 Discord 채널에 일반 답장으로 표시됩니다. 룰렛은 참여 동의와 봇의 역할/음성 권한이 필요합니다.

AI 개인 기억 삭제는 **원본 채팅·미디어·음성 체류 기록을 삭제하지 않습니다.** 관련 저장/삭제 정책은 서버 운영자에게 문의하세요.

개발·호스팅·일회성 슬래시 명령 정리: [README.md](README.md).
