# 기니봇 사용 가이드 — Discord 멤버와 서버 관리자를 위한 README

> **개발자 문서:** [README.md](README.md) · **대상:** 기니봇이 설치된 Discord 서버의 일반 이용자, 서버 관리자, 봇 운영자

기니봇은 **서버 채팅과 음성 채널 활동을 기록**해 통화량·친밀도·활동 순위와 관계 그래프를 보여주고, 일부 서버에서 AI 대화·기억·룰렛·들낙 감지 기능을 제공합니다. 서버와 기능에 따라 사용 가능한 명령이 다릅니다.

> **중요:** 친밀도는 같은 음성방에 있었던 시간이지 친구 관계, 호감도, 실제 발화량을 뜻하지 않습니다. AI 대답과 룰렛은 오락용입니다.

## 1. 30초 사용법

1. Discord에서 기니봇이 들어 있는 서버를 엽니다.
2. 메시지 입력창에 `/`를 입력하고 원하는 명령을 검색합니다.
3. 예: `/통화량`으로 음성 채널 체류 순위를 보거나 `/친밀도 유저:@친구`로 함께 있었던 시간을 봅니다.
4. **전용 서버**에서는 메시지 맨 앞에 `기니봇아`를 붙여 AI에게 질문할 수 있습니다.
5. 결과 카드에 ◀ / ▶가 표시되면 클릭해 다음 순위를 봅니다.

~~~mermaid
flowchart TD
    A[Discord 서버에서 명령 선택] --> B{어떤 기능?}
    B -->|통화 데이터| C[/친밀도 · /통화량 · /통계]
    B -->|관계 시각화| D[/친밀도그래프]
    D --> E{전용 서버 + Activity 준비?}
    E -->|예| F[/친밀도그래프3d]
    E -->|아니오| G[2D PNG로 확인]
    B -->|AI 대화 / 기억| H[전용 서버에서 기니봇아 또는 /memory]
    B -->|관리자 놀이| I[/타겟 · /관리자_타겟 · /관리자머리끄댕이]
~~~

| 기능 | 일반 서버 | 전용 서버 | 필요한 조건 |
| --- | :---: | :---: | --- |
| `/친밀도` | ✅ | ✅ | 음성 기록 |
| `/통화량` | ✅ | ✅ | 음성 기록 |
| `/통계` | ✅ | ✅ | 채팅/음성 기록 |
| `/친밀도그래프` | ✅ | ✅ | 음성 기록 |
| `/친밀도그래프3d` | — | ✅ | Discord Activities 설정 |

**전용 서버**는 코드에서 별도 지정된 서버입니다. 일반 서버에 봇을 초대해도 전용 기능이 자동 개방되는 것은 아닙니다. 관리자 설정으로 특정 명령이 꺼져 있으면 명령이 보이더라도 비활성 안내가 표시됩니다.

## 3. 음성 통계·친밀도

### 3.1 `/친밀도 유저:@사용자`

선택한 사람과 **같은 음성 채널에 동시에 있었던 시간**을 다른 이용자별로 계산해 최대 21명까지 보여줍니다.

~~~text
입력:  /친밀도  유저: @기니
출력:  기니와 같은 통화방에 있었던 사람들의 순위 카드
       [1 ~ 7위] ◀ 1 / 3 ▶ [8 ~ 14위] [15 ~ 21위]
~~~

- 사람이 서로 다른 통화방에 있었던 시간은 합산되지 않습니다.
- 음소거 상태에서도 같은 방에 있었다면 체류 시간이 계산됩니다.
- 겹친 시간이 없으면 빈 결과 카드가 나올 수 있습니다.
- 버튼 페이지는 명령을 실행한 사람만 조작할 수 있으며 약 15분 후 만료됩니다.
- 다른 사용자의 카드를 넘기려 하지 말고 직접 명령을 실행하세요.

### 3.2 `/통화량`

서버 전체에서 음성 채널에 있었던 **누적 체류 시간 상위 21명**을 보여줍니다. 7명씩 카드가 나뉘어 표시되므로 버튼으로 다음 페이지를 확인하세요.

### 3.3 `/통계`

**통화량 · 채팅량 · 종합 활동량** 순위 카드를 확인합니다.

| 카드 | 무엇을 세나 | 주의 |
| --- | --- | --- |
| 음성 | 누적 음성 체류 시간 | 말한 시간과 다름 |
| 채팅 | 저장된 채팅 메시지 수 | 봇이 읽고 저장한 메시지 기준 |
| 종합 | 채팅 수 + 음성 체류 분 단위의 합산 점수 | 서비스 내부 활동 지표이며 공식 Discord 점수 아님 |

통계 카드는 각 항목 상위 7명을 보여줍니다. 실제 활동이 반영되기까지 집계 주기나 백필 시간이 걸릴 수 있습니다.

~~~mermaid
flowchart LR
    A[음성방 입장] --> B[채널 체류 구간 기록]
    B --> C[동일 채널의 두 구간 겹침 계산]
    C --> D[친밀도 순위]
    B --> E[개인별 체류 시간 합산]
    E --> F[통화량 / 통계]
    G[저장된 채팅] --> H[채팅 수 집계] --> F
~~~

**숫자 해석 예:** 두 명이 2시간 동안 같은 음성방에 있었으면 함께 있었던 시간은 최대 2시간입니다. 실제 서로 2시간 이야기했다는 뜻은 아닙니다. 데이터가 없으면 0 또는 기록 없음으로 표시될 수 있습니다.

## 4. 관계 그래프 2D/3D

### 4.1 `/친밀도그래프` — 이미지 한 장

서버의 누적 통화량 상위 20명을 중심으로 연결 관계를 **1920×1080 PNG**로 렌더링합니다.

- **점(노드):** 통화량 상위 멤버.
- **선(링크):** 같은 음성 채널에서 겹친 기록이 있는 관계.
- **선 표시:** 많은 관계 중 상위 관계를 기본 노출하므로 선이 없다고 반드시 전혀 겹친 적이 없다는 의미는 아닙니다.
- 아바타 로딩이 실패하면 대체 표시가 나올 수 있습니다.

### 4.2 `/친밀도그래프3d` — Discord Activity

전용 서버에서 명령을 실행하면 Discord 내부에 3D 관계 화면이 열립니다. 일반 웹 브라우저에서 페이지 URL을 직접 열어도 Discord Activity 인증이 없어 작동하지 않을 수 있습니다.

~~~mermaid
flowchart TD
    A[/친밀도그래프3d 실행] --> B[Discord Activity 열기]
    B --> C[Discord 계정·현재 서버 확인]
    C --> D[기간 선택]
    D --> E[7일]
    D --> F[30일]
    D --> G[전체]
    E --> H[3D 관계망]
    F --> H
    G --> H
    H --> I[사람 1명 클릭: 관계 집중]
    I --> J[다른 사람 클릭: 두 사람 비교]
    I --> K[선택 해제: 전체 화면]
~~~

| 조작 | 의미 |
| --- | --- |
| `7일` | 지금부터 최근 168시간 |
| `30일` | 지금부터 최근 720시간 |
| `전체` | 보관된 전체 음성 기록 |
| 노드 한 번 클릭 | 해당 인물 중심 관계 |
| 다른 노드 클릭 | 두 사용자 비교 |
| 같은 노드 재클릭/선택 해제 | 집중 또는 비교 취소 |

**기간별 20위는 다시 계산됩니다.** 예를 들어 최근 7일에 통화가 많았던 사람이 전체 순위와 다를 수 있습니다. 사용자의 기기가 WebGL을 지원하지 않으면 텍스트 표 보기로 대체될 수 있습니다.

## 5. 기니봇아 AI 대화

전용 서버에서만 사용합니다. 다음 세 가지 호출 방법을 지원합니다.

| 방식 | 예시 |
| --- | --- |
| 접두사 | `기니봇아 오늘 뭐 먹지?` |
| 봇 멘션 | `@기니봇 지금 상황을 한 줄로 정리해 줘` |
| 봇 답장 | 기니봇이 보낸 메시지에 Discord 답장으로 질문 |

**호출 규칙:** `기니봇아`가 **문장 맨 앞**에 있어야 합니다. 단순히 문장 중간에 등장하거나 `기니봇아님`처럼 다른 단어를 붙이면 호출되지 않을 수 있습니다. 이름만 부르고 내용이 없으면 질문을 적어 달라는 안내가 나옵니다.

기니봇의 기본 캐릭터는 **까칠하지만 선을 넘지 않는 존댓말 친구**이고, 설정 파일 `SOUL.md`에 대화 지침이 담겨 있습니다. AI가 말하는 내용은 **정확하거나 검증된 사실을 보장하지 않습니다.** 새 소식 질문은 검색 기능이 켜져 있을 때에만 외부 검색이 사용될 수 있습니다.

### 5.1 `/model`

- `/model`만 입력: 현재 사용하는 OpenRouter 모델 보기.
- `/model name:<모델ID>`: 모델 바꾸기.
- 자동완성 목록에 무료/유료 및 문맥 길이가 표시될 수 있습니다.
- **주의:** 유료 모델을 선택하면 운영자의 OpenRouter 비용이 발생할 수 있습니다.
- 변경은 실행 중 프로세스 상태에 반영되며 재시작 뒤에는 환경변수의 모델로 돌아갈 수 있습니다.

### 5.2 `/reasoning`

- `/reasoning`: 현재 추론 수준과 지원 값을 표시.
- `/reasoning effort:low`: 추론 수준 변경.
- 가능한 값은 `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`이나 **선택한 모델이 전부 지원한다는 뜻은 아닙니다.**

### 5.3 대화가 느리거나 답하지 않을 때

API 지연·호출 한도·사용 중인 모델의 장애로 응답이 늦거나 실패할 수 있습니다. 같은 메시지를 연달아 보내기보다 잠시 후 다시 호출하거나 관리자가 `/mind status` 및 로그를 확인하도록 요청하세요. AI 대화 키가 없으면 통계/기록 등 비-AI 기능은 계속 쓸 수 있습니다.

## 6. AI 기억과 개인정보 선택

Mind는 개인 기억, 다른 사람에게 공유 가능한 기억, 서버 공용 기억을 구분합니다. 개인 기억은 본인이 확인·삭제·공유 범위를 설정할 수 있습니다. **원본 채팅 기록은 별개**입니다.

~~~mermaid
flowchart TD
    U[사용자 대화] --> DEC[기억할 사실 후보]
    DEC --> SCOPE{저장 범위 결정}
    SCOPE -->|본인 사실| P[개인 기억]
    SCOPE -->|다른 사람 관련| G[서버 공용 기억]
    P --> PRIVATE[비공개: 본인 대화에만]
    P --> SHARE[공유 가능: 다른 사람 대화에서 검색 가능]
    G --> ADMIN[관리자 /shared-memory로 관리]
    PRIVATE --> DEL[/memory delete 또는 clear]
    SHARE --> DEL
~~~

### 6.1 누구나 사용할 수 있는 `/memory`

| 명령 | 역할 |
| --- | --- |
| `/memory list` | 본인의 저장된 기억 최대 25개와 번호·공유 범위 확인 |
| `/memory delete id:<번호>` | 본인 기억 하나 삭제 |
| `/memory clear confirm:true` | 본인 기억 전체 및 봇의 관계 추정값 초기화 |
| `/memory visibility id:<번호> visibility:private` | 기억을 비공개로 변경 |
| `/memory visibility id:<번호> visibility:shareable` | 해당 기억을 다른 사람이 검색할 수 있게 공유 |

예를 들어 `기니봇아 내가 고양이를 키우는 거 기억해 줘`라고 말할 수 있습니다. 다만 어떤 내용이 저장될지는 기억 정책과 추출 판단에 달려 있으므로 **반드시 `/memory list`로 확인**하세요.

**`/memory clear`에서 사라지지 않는 것:** 서버 공용 기억, 이미 Discord에서 주고받은 메시지, 봇이 수집한 원본 채팅·미디어·음성 통계, 외부 운영 백업. 완전한 데이터 삭제는 서버 운영자와 별도로 상의해야 합니다.

### 6.2 관리자 전용 `/shared-memory`

| 명령 | 사용 목적 |
| --- | --- |
| `/shared-memory list` | 공용 기억 최대 50개 확인 |
| `/shared-memory add content:<내용> category:fact` | 서버 전체 사실 저장 |
| `/shared-memory add content:<내용> category:preference` | 서버 취향 정보 저장 |
| `/shared-memory add content:<내용> category:server_convention` | 서버 관습 저장 |
| `/shared-memory edit id:<번호> content:<새 내용>` | 공용 기억 수정 |
| `/shared-memory delete id:<번호>` | 공용 기억 삭제 |
| `/shared-memory nickname user:@사용자 nickname:<별명>` | 특정 멤버의 봇 내부 별명 설정(20자 이내) |

공용 기억은 한 사람의 개인 메모처럼 취급되지 않습니다. 대화에 다른 사용자가 등장할 때 개인/공용 저장 범위는 코드 정책에 따라 정해질 수 있으니, 민감하거나 불필요한 정보를 기억시키지 마세요. 별명 기능은 **Discord 서버 프로필을 바꾸는 기능이 아니라** 기니봇이 사람을 부를 때 참고하는 내부 공용 기억입니다.

### 6.3 관리자 전용 `/mind status`

최근 24시간·1분간 Decision API 사용량, 현재 판단 모델, 회로 차단기 상태, 최근 실패율을 보여줍니다. 판단 엔진이 장애를 겪을 때는 폴백 답변으로 이어질 수 있습니다.

## 7. 관리자 러시안 룰렛

**전용 서버의 오락용 기능**입니다. 설정된 역할을 가진 멤버를 대상으로 음성방에서 룰렛을 진행하고, 당첨자를 음성 채널에서 연결 해제할 수 있습니다. 서버 관리자와 참여자는 결과를 미리 알고 동의한 상태에서 사용하세요.

### 7.1 준비 절차

1. 운영자가 Discord 역할/권한을 점검합니다. 봇에게 **역할 관리**, 대상 음성방의 **연결/말하기**, **멤버 연결 해제** 권한이 필요합니다.
2. `/타겟 인자:지정 역할:@참여권역할`로 **실행권** 역할을 정합니다. 실행 시 실행자의 해당 역할은 소비됩니다.
3. `/관리자_타겟 인자:지정 역할:@관리자역할`로 **추첨 대상 역할**을 등록합니다(필요 시 여러 역할).
4. 추첨 대상 역할을 가진 관리자가 음성방에 접속해야 합니다.
5. 참여권 역할 보유자가 `/관리자머리끄댕이`를 실행합니다.

~~~mermaid
flowchart TD
    A[/타겟 설정 / 관리자_타겟 설정] --> B{실행자가 타겟 역할 보유?}
    B -->|아니오| STOP[실행 불가]
    B -->|예| C{음성방에 대상 관리자 있음?}
    C -->|아니오| STOP
    C -->|예| D[실행자 타겟 역할 소비]
    D --> E[무작위 대상 및 방어권 판정]
    E --> F[결과 공지·음성 재생]
    F --> G[선정된 대상 음성 연결 해제 또는 방어]
~~~

| 명령 | 인자 예 | 용도 |
| --- | --- | --- |
| `/타겟` | `지정` + 역할 | 실행권 역할 등록 |
| `/타겟` | `조회` / `삭제` | 실행권 확인/해제 |
| `/관리자_타겟` | `지정` + 역할 | 추첨 대상 역할 추가 |
| `/관리자_타겟` | `조회` / `삭제` + 역할 | 대상 역할 목록·제거 |
| `/관리자머리끄댕이` | 없음 | 룰렛 실행 |

코드에는 방어권 역할 판정이 있으며 **방어권을 정상 소비한 참가자는 65% 확률로 방어 성공**할 수 있습니다. 다만 공개 슬래시 명령에는 방어권 역할을 **새로 등록하는 명령이 없습니다**. 역할 설정은 실제 운영 상태와 코드를 확인해야 하며, 아무 역할이나 자동으로 방어권이 되지는 않습니다. 반복 실행 방지와 역할·음성 권한 검증이 있습니다.

**주의:** 진행 중 역할을 제거하거나 실제로 통화방에서 내보내는 동작이 발생하므로, 타인을 괴롭히기 위한 목적으로 사용하지 마세요.

## 8. 들낙 감지

음성 채널에 들어왔다가 **설정된 시간 안에 나가거나 방을 이동**한 경우를 감지해 지정된 텍스트 채널에 기록합니다. 전용 서버의 관리자만 설정할 수 있습니다.

~~~mermaid
flowchart LR
    JOIN[음성방 입장] --> CLOCK[입장 시각 기록]
    CLOCK --> LEAVE[퇴장 / 방 이동]
    LEAVE --> CHECK{제외 채널? 봇 강제 이동? 기준 이내?}
    CHECK -->|감지 대상| LOG[지정된 채널에 임베드]
    CHECK -->|제외/기준 초과| SKIP[알림 없음]
~~~

| 명령 | 예시/결과 |
| --- | --- |
| `!들낙감지설치` | **현재 텍스트 채널**을 로그 채널로 지정 |
| `!들낙시간지정 30` | 기준을 30초로 변경(가능 범위 1~86400초) |
| `!들낙무시` | 무시 중인 음성 채널 목록 |
| `!들낙무시 123456789012345678` | 해당 음성 채널 제외 |
| `!들낙무시 해제 123456789012345678` | 제외 목록에서 제거 |

- 기본 기준은 **60초**입니다.
- 봇 사용자·동일 방 내 상태 변화 등은 감지하지 않습니다.
- 봇이 룰렛으로 연결을 끊은 전환은 제외합니다.
- 방에 남아 있던 사람을 포함한 알림이 표시될 수 있습니다.
- 입장 시각은 메모리에 있으므로 **봇 재시작 직전 입장 건**은 누락될 수 있습니다.
- 채널 ID는 Discord 개발자 모드에서 음성 채널을 우클릭해 복사할 수 있습니다.

## 9. 관리자용 명령·설정

### 권한 경계

| 그룹 | 누가 사용할 수 있나 |
| --- | --- |
| `!sync`, `!서버목록`, `!서버별명령어`, `!도움` | 봇 코드에 지정된 단일 운영 계정(`ADMIN_USER_ID`) |
| `!들낙감지설치`, `!들낙시간지정`, `!들낙무시` | 전용 서버의 서버 관리자 또는 봇 운영 계정 |
| `/mind status`, `/shared-memory ...` | 전용 서버의 Discord 관리자 |
| `/타겟`, `/관리자_타겟` | 전용 서버의 Discord 관리자 |
| 일반 통계·`/memory` | 기능이 켜진 서버의 해당 사용자 |

**관리자가 운영 계정과 동일한 것은 아닙니다.** `!sync` 같은 관리 명령은 단순히 Discord Administrator 권한을 갖는 것만으로 실행되지 않습니다.

### 명령 목록

| 명령 | 설명 |
| --- | --- |
| `!sync` | 전역·전용 서버 슬래시 명령 재등록 |
| `!서버목록` | 봇이 접속 중인 서버, 기록/통화량 정보 보기 |
| `!서버별명령어` | 서버별 비활성화 명령 확인 |
| `!서버별명령어 서버이름` | 특정 서버의 허용 상태 확인 |
| `!서버별명령어 서버이름 disable 통화량` | 서버에서 `/통화량` 비활성화 |
| `!서버별명령어 서버이름 enable 통화량` | 다시 활성화 |
| `!도움` | 봇 운영자용 기본 도움말 |

서버 이름에 공백이 있어도 사용할 수 있도록 처리합니다. **전용 서버 제한이 우선**이므로 다른 서버에서 `/model` 같은 전용 기능을 허용하는 설정만 해도 실제 사용 가능해지는 것은 아닙니다.

### 관리자가 처음 점검할 것

1. 봇 역할 및 필요한 채널 권한, Message Content Intent.
2. 누가 통계·AI·룰렛에 접근할지 서버 규칙.
3. 초기 백필이 수집하는 공개/제한 채널 범위와 이용자 안내.
4. 통계 카드 이미지의 외부 공유 범위.
5. 룰렛 등 실질적인 역할/음성 변경 기능의 사용 동의.
6. 문제가 생긴 경우 봇 운영자의 Docker/DB 로그 확인.

## 10. FAQ / 문제 해결

**Q. `/` 명령이 안 보여요.**  
A. 앱이 서버에 설치되어 있고 필요한 명령 권한이 있는지 확인하세요. 전용 서버 명령은 일반 서버에서 표시되지 않습니다. 봇 운영자는 `!sync`로 재등록을 요청할 수 있습니다.

**Q. `/친밀도` 결과가 비어 있어요.**  
A. 두 멤버가 같은 음성 채널에 있었던 기록이 없거나 아직 수집되지 않았을 수 있습니다. 디스코드에서 누군가 말을 했는지가 아니라 **체류 구간 겹침**을 계산합니다.

**Q. 내 체류 시간이 Discord 자체와 다르게 느껴져요.**  
A. 봇이 실제 관찰한 기록을 기준으로 하며, 오프라인·재시작·봇이 없던 시간의 음성 활동은 복구되지 않을 수 있습니다. Discord 공식 통화량 수치가 아닙니다.

**Q. 봇을 초대했는데 예전 메시지가 바로 통계에 안 나와요.**  
A. 백필은 읽을 권한이 있는 채널만 순차 수집하며 대형 서버는 처리 시간이 걸립니다. 권한 없는 과거 메시지는 읽을 수 없습니다.

**Q. AI가 대답하지 않아요.**  
A. 전용 서버인지, 접두사가 맨 앞인지, 기능이 켜져 있는지 확인하세요. API 키·모델 장애·한도는 운영자 점검 사항입니다.

**Q. `/memory clear`로 내 채팅 기록도 지워지나요?**  
A. **아니요.** AI 개인 기억과 관계 추정값을 지우지만 별도로 적재된 채팅/미디어/음성 기록은 그대로 남습니다.

**Q. `/shared-memory`가 안 보여요.**  
A. 전용 서버에 있어야 하고 관리자 권한이 필요합니다. `/memory`는 개인 사용자를 위한 별도 명령입니다.

**Q. 3D 그래프를 열었는데 웹 화면이 작동하지 않아요.**  
A. Discord 안에서 Activity로 실행했는지 확인하세요. WebGL 미지원 기기에서는 표 폴백이 나올 수 있고, 서버의 OAuth/HTTPS 매핑이 잘못됐다면 관리자 확인이 필요합니다.

**Q. 룰렛이 시작되지 않아요.**  
A. 타겟 역할, 관리자 타겟 역할, 대상 음성방의 참가자, 봇보다 아래인 역할 서열, 연결/말하기/멤버 이동 권한, 음원 설정을 확인하세요.

**Q. 들낙이 기록되지 않아요.**  
A. 로그 채널이 설치되었는지, 해당 음성방이 무시 목록인지, 기준 시간 안에 실제로 나갔는지 확인하세요. 봇 재시작 당시의 진행 입장은 놓칠 수 있습니다.

**Q. GitHub나 GitLab에서 README를 바꾸면 봇 내용도 바뀌나요?**  
A. 문서 변경은 설명만 바꿉니다. 코드·봇 실행 동작은 별도 배포와 재시작이 필요할 수 있습니다.

### 기록되는 주요 정보

- 읽을 수 있는 서버의 **채팅 메시지 본문·시각·채널·멘션·반응·메시지 상세**.
- 닉네임·아바타 등 관측 가능한 **프로필 이력**.

- 음성 채널의 **입장·퇴장·채널 이동과 체류 시간**. 현재 코드는 실제 통화 오디오를 녹음/전사하는 기능을 제공하지 않습니다.
- AI 기능 사용 시 **대화 문맥·개인/공용 기억·관계 추정 및 Decision 호출 기록**.

### 꼭 알아둘 차이

| 기능 | 이 기능이 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| `/memory delete` | 번호가 지정된 **개인 AI 기억** 삭제 | Discord 메시지 삭제 |
| `/memory clear` | 개인 AI 기억과 관계 추정값 초기화 | 공용 기억/봇의 원본 기록/백업 삭제 |
| `/통화량` | 봇이 관측한 음성 체류 집계 | 실제 발화 녹음·발화 시간 측정 |
| `/친밀도` | 같은 채널 체류 시간 비교 | 감정·친구 관계 진단 |
| `/친밀도그래프3d` | Activity 내 데이터 시각화 | 서버 GPU로 렌더링하거나 무제한 데이터 공개 |

운영자가 데이터 보관/접근/삭제 방침을 별도로 안내해야 합니다. 단순히 Discord 메시지를 지우거나 `/memory clear`를 실행해도 이미 수집된 사본과 백업이 자동 삭제된다고 가정하지 마세요. 필요한 경우 서버 운영자에게 구체적인 데이터 범위와 삭제 요청을 전달하세요.

**이용 예절:** 통계는 경쟁·비하의 근거로 쓰지 않고, 룰렛은 참여자 동의 하에 운영하며, AI에게 주민등록번호·비밀번호·결제 정보 등 민감한 내용을 남기지 않는 것을 권장합니다.
